## Hack&Change 2026 — юридический ассистент с RAG

**Моя роль — ML-разработчик.** Команда Trainers разработала прототип для AI-трека ПСБ. Ассистент ищет фрагменты договоров и законов по ключевым словам (BM25) и по смыслу (BGE-M3), объединяет выдачу через RRF и формирует ответы со ссылками на источники.

В локальной проверке поиск нашёл нужные цитаты в **60 из 60 случаев**.
